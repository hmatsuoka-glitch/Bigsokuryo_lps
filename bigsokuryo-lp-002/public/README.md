# public/

静的アセットを配置するディレクトリ。

## Hero 背景写真

LP-002 の Hero (トップビュー) 背景写真は以下のパスに置いてください:

- `public/hero.jpg`

差し替える場合もファイル名は `hero.jpg` のままにしてください (Hero コンポーネントから固定参照しています)。

### 推奨スペック
- 横幅: 1920px 以上
- アスペクト比: 16:9 程度 (縦長すぎると見切れます)
- 形式: JPG (圧縮で軽量化推奨)
- ファイルサイズ: 300KB 以下を目安

写真が無い場合は navy 単色 + グラデーション装飾だけが表示されます (画像がなくても壊れません)。
